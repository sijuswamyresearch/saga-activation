SAGA Documentation
==================

Welcome to the documentation for **SAGA (Spatially-Adaptive Gated Activation)**.

SAGA is an optimized, plug-and-play activation function featuring fused Triton kernels 
and dynamic gate map extraction capabilities for general deep vision models. Originally 
developed for medical image restoration, SAGA v0.2.0 is designed for high-speed, 
interpretable deep learning across all image processing tasks.
